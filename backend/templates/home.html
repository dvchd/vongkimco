Tính năng chính

🖥️ Desktop app đa nền tảng

Windows · macOS · Linux. Chạy nền, bắt đầu/dừng phiên bằng phím tắt, tự khởi động cùng hệ thống, tự cập nhật qua chữ ký Ed25519.

📸 Ghi nhận hoạt động

Chụp ảnh màn hình định kỳ (mặc định 180s, JPEG ~50%), đếm sự kiện bàn phím/chuột, snapshot ứng dụng foreground.

🔒 Bảo mật & offline-first

Đăng nhập Google OAuth, JWT TTL 1 giờ, refresh token quay vòng lưu trong OS keyring. Hoạt động offline, tự đồng bộ khi có mạng.

📊 Trang quản trị

Tổng hợp người dùng, phiên, ảnh chụp. Quản lý thành viên, duyệt yêu cầu xin gia nhập, trả lời phản hồi.

💬 Phản hồi mở

Mọi người đăng nhập đều gửi được bình luận / báo lỗi / đề xuất tính năng. Rate-limit 8 bài/giờ chống spam.

🛠️ Mã nguồn mở (MIT)

Toàn bộ pipeline viết bằng Rust: Axum + SQLite + Tauri 2 + Svelte. Đọc, fork, tự host trên server riêng đều được.
